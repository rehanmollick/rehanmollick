## 🚀 Selected Projects
- **[NeuroDesign](https://github.com/rehanmollick/NeuroDesign)**: Neuro-marketing for everyday designers — predicts brain region activation on images using Meta's TRIBE v2 model and Gemini 2.5 Flash, rendered as interactive 3D brain visualizations with React Three Fiber.
- **[Karmen LLM Assistant](https://github.com/rehanmollick/karmen-playground)**: Construction scheduling copilot with LLM-powered task generation and Monte Carlo risk simulation for deadline forecasting. Built with FastAPI, Next.js, and Gemini.
- **[SplitPay Escrow](https://github.com/rehanmollick/splitpay-escrow)**: Decentralized escrow protocol for freelance payments with automatic multi-party splits. Built with Solidity, Next.js, and ethers.js on Sepolia testnet.
- **[GridPulse](https://github.com/rehanmollick/gridpulse)**: AI-powered grid dispatch dashboard that predicts demand spikes from simulated load data and generates operator dispatch notes via Groq LLM integration.
